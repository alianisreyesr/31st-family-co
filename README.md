# 31st Family Co

Remake inicial del website de 31st Family Co en React y Vite.

## Requisitos

- Node.js 20 o superior
- npm

## Ejecutar localmente

```bash
npm install
npm run dev
```

Vite mostrará una URL local, normalmente `http://localhost:5173`.

## Crear un build de producción

```bash
npm run build
npm run preview
```
